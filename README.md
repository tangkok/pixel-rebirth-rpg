# Pixel Rebirth · Lineage Chronicles v0.4

เกม RPG **เทิร์นเบสที่ปั้นตัวละครของตัวเองเพียงคนเดียว** เล่นผ่านเบราว์เซอร์บนโทรศัพท์และคอมพิวเตอร์ สร้างด้วย **Phaser 3 + TypeScript + Vite** ได้แรงบันดาลใจจากการเติบโตของตัวละครใน Pixel Lineage และบรรยากาศเกม JRPG แบบ HD-2D ใช้โลก ตัวละคร ฉาก และกติกาของโปรเจกต์เอง

เกมออนไลน์: https://tangkok.github.io/pixel-rebirth-rpg/ (เวอร์ชันใหม่จะพร้อมหลัง workflow Publish browser game สำเร็จ)

## สร้างตัวละครและสายเลือด

ผู้เล่นใหม่เริ่มในเมนูสร้างตัวละคร: ตั้งชื่อ เลือก 1 จาก **6 อาชีพหลัก** และสุ่มเผ่าก่อนเริ่มการผจญภัย เกมมีตัวละครของคุณเพียงคนเดียว อาชีพเสริมไม่ได้เพิ่มสมาชิกปาร์ตี้

สุ่มเผ่าฟรีเริ่มต้น 3 ครั้ง หลังใช้สิทธิ์ฟรี สุ่มใหม่ราคา **150 G จากทองในเกม** แต่ละครั้งแสดงราคาก่อนกด ผลใหม่แทนเผ่าเดิมทันทีและบันทึกก่อนแสดงผล จึงรีเฟรชเพื่อคืนสิทธิ์ไม่ได้ โอกาสรวม 100% และเปิดดูทั้ง 15 เผ่าในเมนูได้:

| ระดับ           | เผ่าและโอกาสต่อครั้ง                             |
| --------------- | ------------------------------------------------ |
| ทั่วไป · 55%    | มนุษย์ 18%, พฤกษาชน 14%, ศิลาชน 12%, พงไพรชน 11% |
| ไม่ธรรมดา · 25% | เอลฟ์จันทรา 10%, อสูรพงไพร 8%, สมุทรชน 7%        |
| หายาก · 12%     | มังกรชน 5%, ภูตดารา 4%, เงาราตรี 3%              |
| มหากาพย์ · 5%   | วิหคเพลิง 3%, ยักษ์เหมันต์ 2%                    |
| ตำนาน · 2.5%    | เซราฟิม 1.5%, สุญญตาชน 1%                        |
| เทพนิยาย · 0.5% | ปฐมเทพ 0.5%                                      |

เผ่าทุกเผ่าเพิ่มค่าสถานะจริง เช่น มนุษย์ HP +12 / ATK +2 และปฐมเทพ HP +80 / MP +20 / ATK,MAG +12 / DEF,SPD +6 ภาพและท่าทางเปลี่ยนตามอาชีพ ส่วนเผ่าแสดงผ่านตราสายเลือดและโบนัส

ผู้เล่นเดิมเข้า **ตัวละครของฉัน** เพื่อเลือกอาชีพ สุ่มเผ่า และปรับบิลด์ได้ทันที เซฟเดิมย้ายมาโดยไม่บังคับสร้างตัวใหม่

## การเล่นบนโทรศัพท์

เปิดลิงก์เกมด้วย Chrome หรือ Safari ไม่ต้องติดตั้ง Node.js หรือแอป รองรับแนวตั้งและแนวนอน ใช้ปุ่มคำสั่งบนจอได้โดยตรง

- **โจมตี**: โจมตีศัตรูเป้าหมายหนึ่งตัว
- **ทักษะ**: เลือกทักษะอาชีพ หรือ Starlight Mend เพื่อฟื้นฟูตัวคุณเอง
- **ป้องกัน**: ลดความเสียหาย 55% จนถึงเทิร์นของตัวเองครั้งถัดไป พร้อมคืน 8 MP และเพิ่ม BP
- **ไอเทม**: ใช้ยา ฟื้น 90 HP ให้ตัวคุณเอง ยาจะไม่ถูกใช้ถ้า HP เต็ม
- **BOOST**: ใช้ 2 BP เพิ่มพลังโจมตีหรือเวทฟื้นฟูครั้งถัดไป 65% BP สูงสุด 3 ทุกคำสั่งเพิ่ม 1 BP และ Guard เพิ่มอีก 1
- แตะศัตรูในฉาก หรือใช้ลูกศร **TARGET** เพื่อเปลี่ยนเป้าหมาย
- ปุ่ม **AUTO** ให้ตัวละครโจมตีปกติอัตโนมัติ ปุ่ม **1× / 2×** ปรับความเร็วการแสดงผล
- ลำดับเทิร์นขึ้นอยู่กับ SPD เกมจะรอผู้เล่นเลือกคำสั่งโดยไม่มีเวลาจำกัด ศัตรูลงมือเฉพาะเทิร์นของตัวเอง

ในแนวนอนบนจอเตี้ย สนามและแถบคำสั่งอยู่คนละแถวของ CSS grid จึงไม่ซ้อนกัน แถบสถานะย่อและปุ่มคำสั่งเรียงแนวนอน รองรับ safe-area และโหมดเต็มจอ ปุ่มใน dock สูงอย่างน้อย 44 CSS pixels

บนคอมพิวเตอร์ใช้ `1` โจมตี, `2` เปิดทักษะ, `3` ป้องกัน, `4` ใช้ยา, `B` บูสต์ และลูกศรซ้าย/ขวาเลือกเป้าหมายได้

## ตัวละครของฉัน

มีตัวละครของคุณเพียงคนเดียว ตั้งชื่อได้ในเมนู **ตัวละครของฉัน** เปลี่ยนอาชีพและจัดแต้มให้ตัวละครเดิมได้โดยไม่เพิ่มสมาชิกปาร์ตี้ หรือแตะการ์ดตัวละครขณะต่อสู้:

| อาชีพ                           | ทักษะเด่น              | แนวทาง                     |
| ------------------------------- | ---------------------- | -------------------------- |
| Dawn Warden · อัศวินรุ่งอรุณ    | Sunbreak · 12 MP       | ทำลายเกราะ 3 เทิร์น        |
| Starweaver · จอมเวทดวงดาว       | Astral Rain · 18 MP    | โจมตีเวทด้วย MAG           |
| Veil Ranger · พรานแห่งม่านหมอก  | Piercing Gale · 12 MP  | ความเร็วสูง ลูกศรทะลุเกราะ |
| Duskblade · นักฆ่าเงาสนธยา      | Shadow Fang · 14 MP    | ทะลุเกราะและดูดเลือด 25%   |
| Dawnkeeper · พาลาดินแห่งแสง     | Radiant Oath · 16 MP   | โจมตีเวทพร้อมฟื้น HP 35    |
| Ember Reaver · เบอร์เซิร์กเพลิง | Crimson Cleave · 14 MP | พลังโจมตีเพิ่มเมื่อบาดเจ็บ |

ทุกอาชีพใช้ Starlight Mend ได้ในราคา 16 MP ตัวละครเริ่มด้วยแต้ม 3 แต้ม เมื่อเลเวลเพิ่มได้รับอีก 2 แต้ม คืนแต้มได้ฟรี:

| แต้ม     | ผลต่อสถิติ     |
| -------- | -------------- |
| Might    | ATK +4         |
| Vitality | HP +18, DEF +2 |
| Spirit   | MAG +4, MP +6  |
| Haste    | SPD +3         |

อัปเกรดอาวุธประจำตัวราคา 100 G เพิ่ม ATK +12 และ MAG +10 การเปลี่ยนอาชีพไม่ลบอัปเกรดที่ซื้อแล้ว กด **นำบิลด์ลงสนาม** เพื่อเริ่มการต่อสู้ใหม่และใช้บิลด์ที่ปรับไว้

## ความสามารถและอาชีพเสริม

นอกจากแต้มสเตตัส ยังมี **AP เพิ่มระดับทักษะหลัก** เริ่ม 1 AP และได้เพิ่ม 1 ทุก 2 เลเวล ทักษะเริ่ม RANK 1 เพิ่มได้ถึง RANK 6 แต่ละระดับเพิ่มพลังทักษะ 12% รวมสูงสุด 60% พลังที่เพิ่มใช้ในการคำนวณความเสียหายจริง และรักษาระดับไว้เมื่อเปลี่ยนอาชีพ

**อาชีพเสริมปลดล็อก LV 2** เลือกได้จาก 5 อาชีพที่ต่างจากอาชีพหลัก เปลี่ยนหรือถอดได้ฟรี ได้โบนัสจากค่าสถานะฐานของอาชีพเสริม: HP/MP/ATK/MAG 12%, DEF 20%, SPD 15% (ปัดเป็นจำนวนเต็ม) และใช้ทักษะของอาชีพนั้นที่พลัง 80% พร้อม MP ตามอาชีพเสริม เช่นอัศวิน + จอมเวทใช้ Astral Rain ได้ หากเปลี่ยนอาชีพหลักให้ตรงกับอาชีพเสริม อาชีพเสริมนั้นจะถูกถอดเพื่อไม่ให้ซ้ำ

การเปลี่ยนเผ่า อาชีพ แต้ม และความสามารถมีผลเมื่อเริ่ม encounter ใหม่ด้วย **นำบิลด์ลงสนาม**

## การเดินทาง

เวอร์ชันนี้เน้นการเลือกด่านและต่อสู้เป็นเทิร์น แทนระบบเดินฟันแบบเวอร์ชันแรก

1. **The Hollow Sanctuary** — ดวลกับผู้พิทักษ์วิหาร
2. **The Sunken Archive** — เผชิญ Archive Wraith ที่รวดเร็วขึ้น
3. **Throne of the Eclipse** — ดวลกับ Eclipse Sovereign

ชนะเพื่อรับทองและ XP พร้อมปลดล็อกด่านถัดไป เล่นซ้ำเพื่อเก็บทรัพยากรได้ เมื่อแพ้สามารถลองใหม่หรือปรับบิลด์ก่อนได้ ทุกการเริ่มด่านเติม HP/MP เต็ม ซื้อยาเพิ่มได้ใน Settings ราคา 25 G

## ภาพและเทคนิค 2.5D

ฉากเป็นภาพ HD ต้นฉบับที่สร้างสำหรับโปรเจกต์ ใช้มุมมอง perspective แบบฉาก 3D ที่เรนเดอร์ไว้ล่วงหน้า แล้วประกอบกับ sprite ตัวละคร แสงผลึก เงา หมอกเคลื่อนไหว อนุภาค และเอฟเฟกต์การโจมตีใน Phaser เป็น **2.5D แบบจัดองค์ประกอบหลายชั้น** ไม่ใช่โลก 3D ที่หมุนกล้องได้อิสระ

ภาพวิหารและ sprite sheet ฮีโร่เป็นภาพต้นฉบับที่สร้างด้วย image generation สำหรับโปรเจกต์นี้ ไม่มีภาพอ้างอิงของผู้ใช้หรือตัวละครจากเกมอื่นอยู่ในไฟล์เผยแพร่ ศัตรูใช้ sprite sheet HD ต้นฉบับชุดใหม่ ส่วน fallback sprites วาดด้วย Canvas บน pixel grid ภาพถูกบีบอัดเป็น WebP พร้อม alpha และโหลดจากโฮสต์เดียวกับเกม Font รวมอยู่ใน build ไม่ใช้ API ระหว่างเล่น

## อนิเมชันและเอฟเฟกต์

Sprite atlas ต้นฉบับใหม่มีท่า idle และ action ของทั้ง 6 อาชีพ แยก frame ด้วย pivot เดียวกัน การโจมตีประกอบด้วยเตรียมท่า → พุ่งหรือยิง projectile → ท่าโจมตี → รับแรงกระแทก → กลับจุดเดิม รวมการหายใจขณะยืน ร่างรับแรงกระแทก การจางหายเมื่อแพ้ ตัวเลขความเสียหาย และอนุภาคที่คืนทรัพยากรหลังจบเอฟเฟกต์

แต่ละอาชีพมีเอฟเฟกต์: คมดาบสีทอง ฝนดาว ลูกศรสีม่วง มีดคู่สีเขียว ลำแสงศักดิ์สิทธิ์ และวงฟันเปลวเพลิง แอนิเมชันเป็น **สองท่าร่วมกับ tween และ procedural effects** ไม่ใช่ชุด skeletal animation เต็มรูปแบบ สถานะการต่อสู้ไม่ขึ้นกับเวลาของภาพ จึงเร่งเป็น 2× ได้ มีตัวเลือก **ลดการเคลื่อนไหวและแสง** ใน Settings และเคารพ `prefers-reduced-motion` ของอุปกรณ์

## ความคมชัดบนมือถือ

เก็บภาพตัวละครที่ 384×576 พิกเซลแทน 96×144 แบบเดิม ภาพศัตรูใช้ frame ความละเอียดสูงจาก sprite sheet และใช้ linear filtering สำหรับงานภาพ HD ไม่ขยายภาพด้วย nearest-neighbor อีกต่อไป

Canvas เรนเดอร์ตาม `devicePixelRatio` ของจอ สูงสุด 3 เท่า เช่นพื้นที่เล่นกว้าง 390 CSS pixels บนจอ DPR 3 ใช้ backing buffer กว้าง 1170 pixels ตัวหนังสือในฉากใช้ความละเอียดเดียวกัน จำกัด GPU buffer ประมาณ 4 ล้านพิกเซลบนจอใหญ่ และปรับ canvas, กล้อง และพิกัดสัมผัสพร้อมกันเมื่อหมุนโทรศัพท์ ไม่ใช้การเพิ่มขนาด CSS เพื่อขยายภาพเล็ก

## เซฟ

เซฟอัตโนมัติใน `localStorage` key `pixel-rebirth-lineage-v4`: เลเวล, XP, เงิน, ยา, ด่านที่ปลดล็อก, ด่านที่ผ่าน, ชื่อ, อาชีพ, แต้มบิลด์, อัปเกรดอาวุธ, เผ่า, สิทธิ์สุ่มเผ่า, สถานะสร้างตัวละคร, อาชีพเสริม, ระดับทักษะ, เสียง และการตั้งค่าลดการเคลื่อนไหว

รีเฟรชแล้วจะเริ่ม encounter ใหม่ด้วย HP/MP เต็ม โดยรักษาความคืบหน้าและจำนวนยาที่ใช้ไป เซฟตัวละครเวอร์ชัน `pixel-rebirth-solo-v3` และเซฟปาร์ตี้เวอร์ชันก่อนใน key `pixel-rebirth-tactics-v2` จะถูกอ่านเพื่อย้ายเลเวล XP เงิน ยา ด่าน และอัปเกรดอาวุธมาสู่ตัวละครคนเดียว โดยไม่ลบเซฟเดิม ผู้เล่นเดิมเริ่มด้วยเผ่ามนุษย์และสิทธิ์สุ่มฟรี 3 ครั้ง เซฟเวอร์ชันแอ็กชันเดิมใน key `pixel-rebirth-save-v1` ยังคงอยู่ และนำทองเดิมมารวมเป็นโบนัสเมื่อเริ่มเวอร์ชันใหม่ครั้งแรก หาก browser storage ใช้ไม่ได้ จะแสดง `SESSION ONLY` และยังเล่นได้ ล้างเซฟเวอร์ชันใหม่นี้ได้ที่ Settings โดยต้องยืนยันอีกครั้ง

เป็นเกมเล่นคนเดียว ไม่มีบัญชีหรือ multiplayer เป็นเวอร์ชันเริ่มต้นที่มี 3 encounter, ฉากหลักหนึ่งฉากพร้อมโทนสีตามด่าน และภาพตัวละครตาม 6 อาชีพ การทดสอบมือถือเป็น Chromium emulation ยังไม่ใช่การทดสอบบนอุปกรณ์จริงหรือ Safari จริง

## พัฒนาและทดสอบ

ต้องมี Node.js 22.12+ หรือ 24+ และ npm

```sh
npm ci
npm run dev
npm run build
npm test
npm run test:e2e
npm run preview
```

Playwright ใช้ `/usr/bin/chromium` ถ้ามี หรือ managed Chromium ของ Playwright ติดตั้ง browser ด้วย `npx playwright install chromium` ได้เมื่อจำเป็น หรือกำหนด `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`

```text
src/
  main.ts             UI, controller, touch/keyboard commands, audio, saves
  style.css           Responsive dark fantasy interface
  game/
    tactics.ts        Pure rules: builds, turns, skills, rewards, saves
    BattleScene.ts    Phaser scene, depth layers, hit effects, animations
    battleArt.ts      High-resolution sprite frames, portraits, fallback art
    display.ts        Device-pixel-ratio sizing with a bounded GPU buffer
    lineage.ts        Six classes, 15 weighted races, secondary-job modifiers
    combatMotion.ts   Class-specific visual profiles and timing
  characterPanel.ts   Creation, race odds, mastery and secondary-job menus
  expansion.css       Separate arena/dock layout and expanded character UI
public/art/           Original compressed environment, hero and enemy sprite sheets
tests/tactics.test.ts Combat/build/save unit tests
tests/lineage.test.ts Creation, odds, six jobs, mastery, subclass and migration
tests/browser/        Functional desktop and mobile browser tests
```

`window.__pixelRebirth` มีเฉพาะโหมด Vite development สำหรับทดสอบและ debug ไม่เปิดใน production

## เผยแพร่

Workflow `.github/workflows/pages.yml` ตรวจ unit tests และ build ก่อน deploy ไป GitHub Pages ทุกครั้งที่ push `main` สามารถสั่งผ่าน **Actions → Publish browser game → Run workflow** ได้ โดยตั้งค่า **Settings → Pages → Source: GitHub Actions** ก่อน
